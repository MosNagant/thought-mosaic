# Thought Mosaic · 浏览器 Demo

Windows、macOS、iOS 和 Android 均可通过现代浏览器体验。原生 iOS 工程仍在上级目录。

零运行依赖的 HTML / CSS / JavaScript，`dist/` 即完整网站，支持静态托管。系统字体、黑白灰色彩和移动端记录页沿用 Group05 Figma 原型；桌面端增加灵感库侧栏。

## 本地启动

```sh
cd web
python3 -m http.server 4173 --bind 127.0.0.1 --directory dist
```

打开 http://127.0.0.1:4173 。摄像头和麦克风仅在 HTTPS 或 localhost 可用。

## 功能

- 新建、编辑、删除、搜索文字和素材记录。
- 图片选择、拖入、剪贴板粘贴和摄像头拍照；图片缩放至最长边 2000 像素。
- 麦克风录音、停止、播放，每段最多 5 分钟。
- 标签搜索、创建、多选，关闭标签弹窗不保存临时选择。
- IndexedDB 保存记录、图片、音频和自动草稿；退出可保留、放弃或继续编辑。
- JSON 备份导出与恢复，导入生成独立副本，不覆盖现有记录。
- Ctrl / ⌘ + Enter 保存；Escape 显示退出确认。

记录仅保存在当前浏览器，不上传、不跨设备同步。清除网站数据会删除本地记录，无痕窗口不保证持久保存。请导出重要记录。音频编码和设备权限由浏览器决定；未实现语音转文字。没有摄像头或麦克风时仍可使用文字与图片。

## 四种快捷唤醒方案

灵感库点击“开始体验”，或者直接打开发布地址加 `?entry=a1`、`?entry=a2`、`?entry=b`、`?entry=c`。

| 方案 | 操作 |
| --- | --- |
| A1 截图 | 模拟截图 → 缩略图下的记录灵感 → 写字/标签 → 保存 |
| A2 组件 | 拍照记录组件 → 拍下示例画面（也可用真实摄像头）→ 保存 |
| B 三指上滑 | 在灰色区域三指上滑；电脑用鼠标向上拖，或点模拟按钮 → 记录 → 保存 |
| C App 图标 | 点击 TM 图标 → 空白记录 → 保存 |

保存后可直接“体验下一种入口”。A1 会生成当前原型灰色画面的图片并附带到记录；A2 示例素材与真实摄像头有明确标注。所有原型入口均只在网页中运行，不截取桌面、不监听其他 App、不修改手机系统。iOS 工程另提供 WidgetKit、分享扩展与 App Shortcuts。iOS 不开放跨 App 三指唤醒或截图浮窗自定义按钮。

## 检查

Node.js 22 或更新版本：

```sh
npm run check
npm test
```

`tests/entries.test.mjs` 验证四方案定义、三指数量、方向、时间和鼠标手势边界。`tests/model.test.mjs` 验证空内容、纯音频、标签去重、搜索、修改识别和保存。交互还需在浏览器中检查：中文组合输入、标签取消、退出三分支、刷新后恢复、图片持久化与小屏布局。真实 Windows 设备上的音视频权限需要测试者授权后验证。
